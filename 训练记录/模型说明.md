# 模型说明

## 一、来源与最初框架版本

- **算法**：Conv-TasNet（Luo & Mesgarani, *Conv-TasNet: Surpassing Ideal Time-Frequency Magnitude Masking for Speech Separation*, IEEE/ACM TASLP 2019）。
- **最初框架版本 / 参考实现**：asteroid（本机 vendored 版 `0.7.1dev`；公开预训练权重按 asteroid 0.7.0 口径训练）。
- **训练起点**：HuggingFace `JorisCos/ConvTasNet_Libri2Mix_sepclean_16k`（在 Libri2Mix sepclean 16k 上训好的 Conv-TasNet；
  20 394 640 B / md5 `42e901d57d7c2f79b9d8a74a8077b7b0`，随包在 `代码/pretrained/`；
  该权重以 **CC BY-SA 4.0** 授权（署名 Cosentino Joris），本仓库的微调权重是它的**改编物**，
  同样以 CC BY-SA 4.0 提供 —— 详见仓库根目录 `THIRD_PARTY_NOTICES.md`）。
- **本模型**：在上述起点上微调 30 轮，并在 `masker.bottleneck` 处接入 6 路 ITD/ILD 空间特征（见第三节）。
- **训练环境**：PyTorch 2.11.0+cu128。

## 二、结构参数（逐字抄自官方配方）

`fb_name = FreeFB`；`n_filters = 512` / `kernel_size = 32` / `stride = 16`；
`bn_chan = 128` / `hid_chan = 512` / `skip_chan = 128` / `conv_kernel_size = 3`；
`n_blocks = 8` / `n_repeats = 3`；`n_src = 2` / `norm_type = gLN` / `mask_act = relu` / `encoder_activation = None`；
`in_chan = 512` / `out_chan = 512`。
（配方里的 `sample_rate = 8000` 是官方自己写错的值 —— 前向只走 `model(wav)`，不要用 `model.separate()`。）

## 三、本模型相对官方底座做的改动

**唯一改动**：`masker.bottleneck` 的 1×1 卷积输入通道 **512 → 518**
（新增 6 列接 6 路 ITD/ILD 空间特征，初值 0），其余（编码器 / TCN / 解码器 / mask 头）一字未改。

| | 官方底座 | 本模型 |
|---|---|---|
| `bottleneck` 输入通道 | 512 | **518** |
| 参数量 | 5 066 929 | **5 067 697**（+768 = 6 × 128） |
| FLOPs（1 秒输入） | 9.9436 G | 9.9451 G |
| RTF（4 秒，稳态） | 0.0051 | 0.0049 |

拼接点写在 `GlobLN` **之后**：起点权重下新列贡献恒为 0，输出与官方底座**逐元素恒等**；
而新列的梯度不为 0，空间线索照样能学进去。代价是空间特征不经过 `GlobLN` ——
它已经被训练集统计量 z-score 标准化过，再走一次 `GlobLN` 等于被全局统计量二次归一。
（论证细节见 `代码/conv_tasnet_spatial.py` 头部注释。）

## 四、微调口径

起点同上；训练集 5777 条 / 原始 20.46 h（装载丢弃短于 3 s 的 132 条 → 每 epoch 5645 条 / 可用 20.37 h）；
Adam，lr 1e-4 + warmup 500 步 + 余弦退火、weight decay 0；batch 2 × 累积 4 = 有效 8；3 s 段（48000 样本）、
PIT SI-SDR 损失、梯度裁剪 5；`--deterministic` 开、seed 26；30 epoch、交付最后一个 epoch、不做验证集与早停；
30 epoch 实测 **19 090 s（≈5.3 h，约 4.1 it/s）**。

## 五、怎么加载

```python
import sys; sys.path.insert(0, "代码")
from model_io import load_model, infer

model, info = load_model(ckpt="ckpt_ep30.pt", device="cuda")
# info: {"ckpt": ..., "epoch": 30, "loaded_from": ..., "device": "cuda", "n_params": 5067697}
```

- `build_spatial_model()` 先造结构（在官方底座上把 `masker.bottleneck` 的 1×1 卷积
  从 `(128, 512, 1)` 扩成 `(128, 518, 1)`，**新增 6 列权重置 0**），再灌 `ckpt`。
- 底座查找顺序：本地 `代码/pretrained/ConvTasNet_Libri2Mix_sepclean_16k/` → HuggingFace
  `JorisCos/ConvTasNet_Libri2Mix_sepclean_16k`。**离线机器必须带 `代码/pretrained/`**。
- 权重严格比对：形状对不上会当场报
  `checkpoint 与模型不匹配：... [('masker.bottleneck.1.weight', (128, 512, 1), (128, 518, 1))]`
  —— 这是有意为之，避免 512 宽度的权重被静默丢弃、模型表面照跑却等于没接空间特征。

## 六、输入口径

| 输入 | 形状 / 要求 |
|---|---|
| 波形 | `[T]` float32、**16000 Hz**、**单通道**；取 `ref_channel = 1`（linear3 中心麦），源 wav 是 7 通道 |
| 空间特征 | `[6, N]` float32；通道顺序 `ch0..5 = itd_01, ild_01, itd_02, ild_02, itd_12, ild_12`（`linear3` 的 (0,1)(0,2)(1,2) 三对 x ITD/ILD）；1000 Hz（hop = 16 样本）；**已 z-score** |
| 输出 | `[2, T]` float32（两路分离结果；按与单源参考的 SI-SDR 选目标路） |

帧数关系：编码器帧数 `L = (T - 32) // 16 + 1`；空间特征帧数 `N` 应等于 `T // 16`，
即比 `L` 多 1 帧 —— 推理时**只取前 L 帧**；`N` 比 `L` 多超过 `MAX_EXTRA_FRAMES = 2` 会直接报错（防错位）。

## 七、空间特征从哪来

`spatial_feat.py`（随本仓库，与训练侧口径逐位一致）：

- ITD：GCC-PHAT，限带 2-4 kHz，抛物线亚样本插值；ILD：全带能量比 `10*log10(E0/E1)`
- 分析窗 512 样本汉宁窗、hop 16；标准化用**全局统计**（`space_feat_stats.json`，6 通道版）
- 自查：`python spatial_feat.py --selftest`；看单条 wav：`--wav 样本.wav --save-npy out.npy --stats space_feat_stats.json`

## 八、常见报错

| 报错 | 原因 |
|---|---|
| `空间特征形状应为 [6, N]，实际 (2, N)` | 用了 2 通道时代的旧特征 |
| `空间特征帧数 X 与波形长度 Y 不匹配：应为 Z 帧，最多多 2 帧` | 特征与波形不是同一条，或帧数口径不对 |
| `LocalEntryNotFoundError` | 离线且没有 `代码/pretrained/` |
| `ModuleNotFoundError: No module named 'asteroid'` | 依赖没装齐（只有训练侧实现需要 asteroid；跑交付面的 `separate.py` 不需要） |
