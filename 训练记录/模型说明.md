# 模型说明（臂 B · 目标模型）

## 一、怎么加载

```python
import sys; sys.path.insert(0, "代码")
from arm_models import load_arm, infer

model, info = load_arm("B", ckpt="ckpt_B_ep30.pt", device="cuda")
# info: {"arm": "B", "ckpt": ..., "epoch": 30, "loaded_from": ..., "device": "cuda", "n_params": 5067697}
```

- `load_arm("B")` 会先 `build_arm_b()` 造结构（在官方底座上把 `masker.bottleneck` 的 1x1 卷积
  从 `(128, 512, 1)` 扩成 `(128, 518, 1)`，**新增 6 列权重置 0**），再灌 `ckpt`。
- 底座查找顺序：本地 `代码/pretrained/ConvTasNet_Libri2Mix_sepclean_16k/` -> HuggingFace
  `JorisCos/ConvTasNet_Libri2Mix_sepclean_16k`。**离线机器必须带 `代码/pretrained/`**。
- 权重严格比对：把臂 A 的权重灌进臂 B 会当场报
  `checkpoint 与臂 B 不匹配：... [('masker.bottleneck.1.weight', (128, 512, 1), (128, 518, 1))]`
  —— 这是有意为之，避免 512 宽的权重被静默丢弃、两臂变成自己跟自己比。

## 二、输入口径

| 输入 | 形状 / 要求 |
|---|---|
| 波形 | `[T]` float32、**16000 Hz**、**单通道**；本项目取 `ref_channel = 1`（linear3 中心麦），源 wav 是 7 通道 |
| 空间特征 | `[6, N]` float32；通道顺序 `ch0..5 = itd_01, ild_01, itd_02, ild_02, itd_12, ild_12`（`linear3` 的 (0,1)(0,2)(1,2) 三对 x ITD/ILD）；1000 Hz（hop = 16 样本）；**已 z-score** |
| 输出 | `[2, T]` float32（两路分离结果；本项目按与单源参考的 SI-SDR 选目标路） |

帧数关系（`P-33`）：编码器帧数 `L = (T - 32) // 16 + 1`；空间特征帧数 `N` 应等于 `T // 16`，
即比 `L` 多 1 帧 —— 推理时**只取前 L 帧**；`N` 比 `L` 多超过 `MAX_EXTRA_FRAMES = 2` 会直接报错（防错位）。

## 三、空间特征从哪来

`sim/spatial_feat.py`（在 `TSE_评测链路补件`，或真源 `D:\tse_project\sim\`）：

- ITD：GCC-PHAT，限带 2-4 kHz，抛物线亚样本插值；ILD：全带能量比 `10*log10(E0/E1)`
- 分析窗 512 样本汉宁窗、hop 16；标准化用**全局统计**（`space_feat_stats.json`，6 通道版）
- 增量补档**必须** `--reuse-stats`（否则新旧样本尺度不一致）；整批重做才用 `--recompute-stats`

## 四、常见报错

| 报错 | 原因 |
|---|---|
| `空间特征形状应为 [6, N]，实际 (2, N)` | 用了 2 通道时代的旧特征 |
| `空间特征帧数 X 与波形长度 Y 不匹配：应为 Z 帧，最多多 2 帧` | 特征与波形不是同一条，或帧数口径不对 |
| `LocalEntryNotFoundError` | 离线且没有 `pretrained/` |
| `ModuleNotFoundError: No module named 'asteroid'` | 依赖没装齐（模型结构类来自 asteroid 0.7.0） |


## 五、最初框架版本与来源

- **算法**：Conv-TasNet（Luo & Mesgarani, *Conv-TasNet: Surpassing Ideal Time-Frequency Magnitude Masking for Speech Separation*, IEEE/ACM TASLP 2019）。
- **参考实现**：asteroid（本机 vendored 版 `0.7.1dev`；公开预训练权重按 asteroid 0.7.0 口径训练）。
- **起点**：HuggingFace `JorisCos/ConvTasNet_Libri2Mix_sepclean_16k`（Libri2Mix sepclean 16k 上训的 Conv-TasNet；
  20 394 640 B / md5 `42e901d57d7c2f79b9d8a74a8077b7b0`，随包在 `代码/pretrained/`）。
- **训练环境**：PyTorch 2.11.0+cu128。

## 六、结构参数（两臂共用，逐字抄自官方配方）

`fb_name = FreeFB`；`n_filters = 512` / `kernel_size = 32` / `stride = 16`；
`bn_chan = 128` / `hid_chan = 512` / `skip_chan = 128` / `conv_kernel_size = 3`；
`n_blocks = 8` / `n_repeats = 3`；`n_src = 2` / `norm_type = gLN` / `mask_act = relu` / `encoder_activation = None`；
`in_chan = 512` / `out_chan = 512`。（配方里的 `sample_rate = 8000` 是官方自己写错的值 —— 前向只走 `model(wav)`。）

**臂 B 唯一改动**：`masker.bottleneck` 的 1×1 卷积输入通道 **512 → 518**（新增 6 列接 6 路 ITD/ILD 空间特征，初值 0），
其余（编码器 / TCN / 解码器 / mask 头）一字未改。参数量：臂 A **5 066 929** / 臂 B **5 067 697**（+768 = 6 × 128）；
FLOPs（1 秒输入）9.9436 G / 9.9451 G；RTF（4 秒，稳态）0.0051 / 0.0049。

## 七、微调口径（两臂完全相同）

起点同上；训练集 `data/sim_train_20h` **5777 条 / 原始 20.46 h**（装载丢 132 条短于 3 s → 每 epoch 5645 条 / 可用 20.37 h）；
Adam，lr 1e-4 + warmup 500 步 + 余弦退火、weight decay 0；batch 2 × 累积 4 = 有效 8；3 s 段（48000 样本）、
PIT SI-SDR 损失、梯度裁剪 5；`--deterministic` 开、seed 26；两臂各 30 epoch、交付最后一个 epoch、不做验证集与早停；
臂 B 单臂 30 epoch 实测 **19 090 s（≈5.3 h，约 4.1 it/s）**（臂 A 同一份数据同样 30 epoch 是 21 247 s）。
